**How to read the columns.**

- **id** — the inventory's id. A suffix (/1D, /clock, /phone, /house, /input, b, -phone) or an S-, L- or 6c- id marks a run row with no inventory id of its own; §2 is a language feature from area D's inventory, which gave it none.
- **works** — the run's action → what was expected, then the result at 521d7de: PASS, **FAIL** (what was seen) → its state now (the commit that fixed it and the check that guards it), or manual (the run could not decide it by script; the reason follows).
- **ms** — from the action to the observed result, on a machine shared with two other browser agents: read as upper bounds. "—": the run timed nothing.
- **redundant with** — another control, indicator or code path that does the same thing (from the inventories). "(also …)" in the item column names the same item listed in another area, which is not a redundancy.
- **global UI** — "house:" names the shared component, tokens, formatter or key list it uses; "one-off:" names the local piece.
- **looks right** — "(run)": what a run saw. "sweep ✓": the item stands in the pane at rest, and the looks sweep (1440 × 900, 1280 × 720 and 390 × 844, dark and paper, one to four panes) found 0 overlaps and 0 truncations at da5b42f — [shots/looks/](shots/looks/). "colour vision ✓": the colour-vision check (the blue-orange pair, on black and on paper) — for the ovals, the ladder and the indicator inks only. "not checked": no run or sweep looked at it in a theme, at phone width or under colour vision.
- **shot** — a picture in this folder that shows the item: exercise/area-c-*.png from the area C run (521d7de), shots/looks/ from the sweep (da5b42f), shots/item1-* from §1 of the README. Each shows its own commit, before 9115af0.
